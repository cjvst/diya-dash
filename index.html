Setup tips
  1. Open the link once on Wi-Fi before the shift: after that it works even without signal.
  2. Add it to the home screen (browser menu → Add to Home screen). On iPhone this hides the browser bars.
  3. Screen brightness to maximum, volume up, silent mode off.
  4. Set the stall code above. It appears on every result screen.
  5. Tap “Prize given” when you hand a prize over: the card is stamped and today’s counts stay right.
  6. Keep the phone on charge between rushes; it rests itself on the start screen.
